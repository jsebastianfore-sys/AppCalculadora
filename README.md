# Calculadora - Ionic & Angular

Aplicación de calculadora desarrollada con **Ionic**, **Angular (Standalone Components)**, **TypeScript** y **SCSS**, compilada para dispositivos móviles Android utilizando **Capacitor**.

---

## 🚀 Características

- Operaciones aritméticas básicas: Suma, resta, multiplicación y división.
- Funciones científicas: Potenciación ($x^2$) y funciones trigonométricas ($\sin$, $\cos$, $\tan$) convertidas automáticamente a grados.
- Pantalla de resultados con manejo de errores (por ejemplo, división por cero).
- Diseño responsivo en cuadrícula (Grid CSS de 4 columnas) con botones adaptados para dispositivos móviles.
- Interfaz moderna y personalizada con estilos BEM y paleta de colores propia.

---

## 🛠️ Tecnologías y Herramientas Utilizadas

* **Framework:** Ionic v8+ / Angular v18+ (Componentes Standalone)
* **Estilos:** SCSS / CSS Grid
* **Plataforma Nativa:** Capacitor (@capacitor/android)
* **Entorno de Desarrollo:** Visual Studio Code & Android Studio
* **Control de Versiones:** Git
